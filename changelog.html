更新日志

从 v1.0.0 开始

v1.0.0 是咕咕启动器的第一个版本，这里先只有它一条，完整说明已默认展开。以后每发布一个版本会在最上方新增一条，最多保留最近 5 条，默认只展开最新那条；点标题即可展开或收起。

修复

  • 壁纸引擎可以正常应用，视频壁纸在预览框与背景层都能播放。
  • 本地图不再提示「目录不存在」：默认目录改到当前数据根下的 backgrounds，并会自动创建。
  • 官方皮肤可以直接上传到 Microsoft 账号（内置皮肤没有磁盘路径的问题已修）。
  • 离开皮肤页再回来不会变回 Steve：正版账号显示 Microsoft 账号当前使用的皮肤，并带缓存。
  • 「恢复正版皮肤」不再重复下载：已在本地就直接复用，接口 60 秒节流、按钮 30 秒冷却。
  • Java 版本列表补全：选「全部」合并所有来源，选单个镜像能看到该源的全部大版本。
  • 新建实例可以选加载器与具体版本（Fabric / Forge / NeoForge）。
  • 下载源不再被误判为「不可用」：探测改为对真实清单读取 1 字节，只有超时或服务端错误才算失败。

新增

  • 第三方账号登录（Yggdrasil / authlib-injector，例如 LittleSkin）：三标签添加账号、站点地址与密码、刷新登录，首次自动下载 authlib-injector 并在启动时挂载。
  • 第三方账号在皮肤页为只读预览：只显示该账号在皮肤站正在使用的皮肤，上传与修改按钮全部禁用。

其他

  • 首次安装默认「关闭窗口时：每次询问」「更新方式：手动更新」。
  • 整合包在资源列表与详情里统一显示「创建并安装」。

内核与体积

  • 整套启动器用 Rust + Tauri 2 重写：安装包 3 MB 级，安装后约 8 MB；Electron 版为 89 MB。
  • 所有数据收在安装目录下的 .mc 里：实例、依赖库、资源、皮肤、日志、数据库都在同一个目录；卸载时会连 .mc 一起清理干净。
  • 内置 NSIS 中文安装向导，安装包使用正式 logo。

下载

  • 下载源三选一：官方、BMCLAPI、自定义镜像，并自动测速选最快的一条。
  • 同时下载数（默认 8）与每个文件的分片线程数（默认 4）都可以调。
  • 支持跨源回退与断点重试，遇到 429 会自动退避重试。
  • 右上角的下载中心与设置里的下载中心是同一份任务流，进度不会对不上。

启动与 Java

  • 版本安装会自动完成客户端、依赖库、资源与 natives 的自检补齐。
  • Java 管理：自动扫描本机 JDK，按目录去重，显示每个运行时的 javaw 路径与来源。
  • 内置 Java 下载：清华 TUNA、兰州大学、Zulu（injdk）、Oracle（injdk）、Microsoft OpenJDK 与 Azul 六个镜像，自动测速选最快，镜像之间自动互备。
  • Oracle 官方 JDK 只提供下载页入口（需接受 OTN 许可），不直接抓包。
  • 启动时若缺少对应大版本的 Java，会自动下载并补齐（可以在设置里关掉）。
  • 支持离线账号与微软账号；实例级可设置内存、窗口大小、Java 与图标，并记录游玩时长。

资源

  • 模组、光影、资源包与存档都能启用或停用、导入、删除。
  • 存档支持导出，实例包支持导出分享。
  • 模组、光影与资源包都支持一键检查更新与批量更新，更新前会把原文件备份到实例目录里。
  • 1.20 及以上版本的存档可以「进入该存档」直接启动游戏；更低版本会提示不支持。

种子地图

  • 内置 cubiomes（MIT）在本地计算指定种子的地形：输入种子即可看到生物群系地图，支持拖拽平移与 1 / 2 / 4 / 8 / 16 / 32 / 64 像素每方块的离散缩放。
  • 图层可开关：地貌阴影、悬停显示群系名与坐标、16×16 区块线、结构标记。
  • 结构搜索覆盖村庄、海底神殿、林地府邸、要塞、下界要塞、堡垒、掠夺者前哨、沉船、海底废墟与宝藏；「高亮地形」可按群系名把目标区域留亮、其余压暗。
  • 坐标栏可前往指定 X/Z、复制 TP 指令、跳到出生点；支持 1.21.x 到 26.3 的版本选择，全部计算在本机完成，不联网。

主页新闻

  • 主页读取 Minecraft 官方新闻接口（launchercontent），显示最新一条，带封面图与中文译文；可切换「原文」，「阅读全文」跳转到中文官网对应的文章页。

皮肤

  • 内置官方 Steve 与 Alex 皮肤（离线账号默认 Steve），3D 预览支持动作播放、旋转缩放、经典与纤细模型以及披风显示。
  • 输入正版玩家名即可一键获取他的皮肤（走 uapis 公开接口）。
  • 第三方皮肤站按 authlib-injector / Yggdrasil 兼容方式接入（例如 LittleSkin），只做预览、不登录。
  • 官方默认皮肤共 9 套（Steve、Alex、Ari、Efe、Kai、Makena、Noor、Sunny、Zuri），每套都带经典与纤细模型。
  • 正版账号可以把当前预览的皮肤上传到 Microsoft 账号并同步披风设置（上传前有二次确认）；离线与第三方账号只做本地应用。
  • 披风设置：仅正版账号会列出可选披风，离线与第三方账号会明确提示不支持。
  • 本地皮肤支持导入、拖入与删除（删除当前皮肤会回退到 Steve），内置皮肤只出现在「官方皮肤」里，不再混进本地列表。
  • 「恢复正版皮肤」按钮：一键取回 Microsoft 账号当前正在使用的那套皮肤，先本地预览再落盘保存；账号用的是默认皮肤时会提示并套用 Steve / Alex。

开服与联机

  • 多人页分为「服务器」与「联机房间」两部分。
  • 一键创建本地服务端：原版、Paper、Purpur、Fabric、Forge、NeoForge 六种核心，核心文件从官方源下载。
  • 自动生成 server.properties、eula.txt 与启动脚本，支持启动、停止、查看日志与端口占用检测。
  • 陶瓦 Terracotta 联机已内嵌进安装包（AGPL-3.0，随包附许可与源码说明），开箱即用，开主机或用联机码加入。
  • 服务端管理：进入服务器可管理模组与插件（启用/停用、从资源页安装）、查看存档并可一键打包备份、表单化编辑 server.properties、查看实时日志。

外观与个性化

  • 背景四方案互斥：渐变色、本地图片、API 图片、Steam 壁纸引擎；本地与壁纸方案每页 20 张预览，支持单张或轮播。
  • 深浅色主题，默认浅色，右上角月亮一点就切成太阳；主题色可调，按钮、边框与文字会跟着变。
  • 显示字体可从系统已装的中文字体里选，默认微软雅黑，切换即时生效。
  • 悬浮窗出现时，下层界面走毛玻璃效果。

内容服务与娱乐

  • Modrinth、CurseForge 与 MCIM 三个来源，覆盖模组、整合包、资源包、光影与数据包；支持排序与每页条数，用分页器翻页。
  • 资源简介走内置的 uapis / suapi 通道翻译并带限流，也可以自填 OpenAI 兼容接口，译文就地替换；CurseForge 资源可用自己填写的 API Key。
  • 选中版本即可一键安装到实例；整合包则是直接创建一个新实例并装进去。
  • 资源类型新增「插件」，可一键安装到自建服务端。
  • 筛选抽屉按内容类型给不同选项（加载器、分辨率、类别），选完点「完成」才生效，已选条件显示成可单独删除的标签。
  • 每日一言（接口地址可自定义）与每日人品（按日期 + 本机种子计算）。
  • GitHub 加速下载器：六个节点自动选最快的那个。

系统集成

  • 系统托盘：左键唤起主窗口，右键菜单可显示主窗口、打开数据目录或退出。
  • 关闭窗口行为三选一：每次询问、最小化到后台、直接退出。
  • 单实例运行：再次启动会给出提示，并把已有窗口切到前台。
  • 数据目录可以迁移：复制并校验通过后切换，切换后需要重启。
  • 可以直接从 HMCL / PCL2 的数据目录导入实例：默认引用原目录（不复制、不改动原数据），也可以复制到咕咕目录。

更新

  • 更新策略三档：自动、手动、关闭。
  • 更新包取自 GitHub Releases（GuguLauncher-Setup.exe，文件名不带版本号），下载前强制测速选最快节点，静默安装完成后自动重启。
  • 版本号支持 tag 与标题纯数字两种写法。

其他

  • 界面目前只有简体中文。
  • 窗口最小 1024×640，布局自适应。
