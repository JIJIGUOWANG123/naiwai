特性

该有的都有，不该有的一个都没有

重写不是换一层皮：内核、数据目录、下载链路全部重做，只留下真正会用到的东西。

  • Rust + Tauri 2 重写

    安装包 3 MB 级，装完约 8 MB，而 Electron 版要 89 MB。内置 NSIS 中文安装向导，冷启动更快、内存占用更低。

  • 数据都收在一个 .mc 目录

    实例、依赖库、资源、皮肤、日志、数据库同处一个目录；卸载连 .mc 一起删净；目录可迁移，复制并校验后切换（需重启）。

  • 下载与更新都挑最快的一条

    官方、BMCLAPI、自定义镜像三选一加自动测速；并发数与分片线程可调，跨源回退、429 退避、断点重试都替你处理好。

  • 启动与 Java 都替你办好

    版本安装自动补齐客户端、依赖库、资源与 natives；自动扫描本机 JDK（按目录去重、显示 javaw 路径），五个来源内置下载，缺大版本会自动补齐。

  • 资源、新闻与皮肤都在里面

    Modrinth / CurseForge / MCIM 三源，覆盖模组、整合包、资源包、光影与数据包，排序分页、译文就地替换、一键装进实例；主页直读官方新闻，皮肤支持 3D 预览与正版名获取。

  • 外观四方案，互斥可选

    渐变色、本地图、API 图、Steam 壁纸引擎一次只生效一种，每页 20 张预览、可单张或轮播。深浅色与主题色随意调，悬浮窗出现时底层毛玻璃。

  • 开服与联机

    一键建原版、Paper、Purpur、Fabric、Forge、NeoForge 服务端，自动生成配置与启动脚本；陶瓦联机开主机或用联机码加入。

  • 单实例、托盘与小工具

    再次启动会提示并把已有窗口切到前台；托盘左键唤起、右键有菜单；关闭窗口行为三选；另有每日一言、每日人品与六节点 GitHub 加速下载器。
